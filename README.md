# Future Home – Construction Project Management System

## Project Overview
Future Home is a construction project management system developed to manage properties, projects, tasks, materials, sustainability tracking, inquiries, and cost estimation. The system also includes an Augmented Reality (AR) module for visualizing construction models.

## System Architecture
The system follows a client-server architecture:
- Frontend: React (Vite)
- Backend: Node.js with Express
- Database: SQL Server

## Project Structure
Future-Home-CGP-project
│
├── client      -> Frontend React Application
├── server      -> Backend Node.js API
├── Data base   -> SQL Scripts and Database Design
├── README.md
└── .gitignore

## How to Run the Project

### Frontend
cd client  
npm install  
npm run dev  

### Backend
cd server  
npm install  
node index.js  

Backend runs on http://localhost:5000  
Frontend runs on http://localhost:3000
