# Future Home – Smart Construction & Real Estate Management System

## Project Description
Future Home is a web-based system designed to manage construction projects,
properties, tasks, materials, sustainability analytics, AR visualization,
and customer inquiries in a centralized platform.

## Technologies Used
Frontend: React.js (Mantis Template)
Backend: Node.js + Express
Database: Microsoft SQL Server

## System Modules
- User Authentication
- Dashboard
- Property Management
- Project Management
- Task Management
- Material Management
- Sustainability Analytics
- AR Viewer
- Inquiry Management

## How to Run Frontend
cd client
npm install
npm start

## How to Run Backend
cd server
npm install
node index.js
